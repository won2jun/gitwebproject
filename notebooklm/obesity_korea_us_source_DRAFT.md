## 1. 비만은 얼마나 흔하고, 어떤 집단에서 높은가?

### 대한민국 (국민건강영양조사, 19세 이상, BMI ≥ 25 kg/m²)
| 구분 | 유병률 |
|---|---|
| 성인 전체 2016년 | 34.8% |
| 성인 전체 2025년 (잠정치) | 39.5% (10년 동안 약 14% 증가) |
| 남성 2025년 | 49.1% (2024년보다 0.3%p 높음, 큰 변화 없음) |
| 여성 2025년 | 28.7% (2024년보다 2.5%p 높음) |
| 남성 30대 | 59.0% |
| 남성 40대 | 53.3% |
| 남성 50대 | 54.0% |

- 비만율이 가장 높은 집단: **30~50대 남성** (절반 이상이 비만)
- 여성은 30·40대에서 크게 늘었음
- `[원문 확인 필요]` PHWR 19권 8호에 실린 연도별 추이, 연령·소득·지역별 수치

### 미국 (NHANES 2021년 8월~2023년 8월, 20세 이상, BMI ≥ 30)
| 구분 | 유병률 |
|---|---|
| 성인 비만 | 40.3% |
| 고도비만 (BMI ≥ 40) | 9.4% |
| 20–39세 | 35.5% |
| 40–59세 | 46.4% (가장 높음) |
| 60세 이상 | 38.9% |
| 학사 학위 이상 | 31.6% (다른 학력 집단보다 낮음) |

- 2013–2014년부터 2021–2023년까지 연령 보정 비만율은 **통계적으로 유의한 변화가 없었음**
- 여전히 Healthy People 2030 목표(36.0%)보다 높음
- `[원문 확인 필요]` 성별 수치, 성별 고도비만, 학력별 전체 값

## 3. 나라별 사례와 차이 — ⚠️ 해석할 때 주의할 점

- 한국 39.5%와 미국 40.3%는 **비슷해 보이지만 직접 비교하면 안 됨**.
  한국은 BMI 25 이상, 미국은 BMI 30 이상을 비만으로 봄. 같은 기준(BMI ≥ 30)을 쓰면 한국 비율은 훨씬 낮아짐 `[같은 기준 수치는 출처 확인 필요]`.
- 연령 범위도 다름 (19세 이상 vs 20세 이상).
- 공통점: 두 나라 모두 **중년층**에서 비만율이 가장 높음 (한국 30~50대 남성, 미국 40–59세).
- 차이점: 한국은 **성별 격차가 큼** (남 49.1% vs 여 28.7%). 미국은 `[성별 수치 확인 필요]`.

## 4. 평균만으로는 알 수 없는 차이

- 한국 성인 평균 39.5% → 남성 49.1%, 여성 28.7%로 나누면 **20%p 넘게 차이**가 남.
- 남성 30대는 59%. 평균보다 약 20%p 높음.
- 미국 평균 40.3% → 학사 이상 31.6%. 학력에 따른 격차가 있음.
- 전체 평균이 그대로여도(미국 2013–2023) 집단 안의 분포는 다를 수 있음 → 집단별로 나눠 봐야 함.
